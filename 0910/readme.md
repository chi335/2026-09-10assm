# 컴퓨터 구조 및 프로세스 메모리 정리

## 1. 레지스터 (Register)
- **개념**: CPU(중앙처리장치) 내부(On-chip)에 위치한 초고속 임시 기억장치입니다.
- **특징**:
  - 메인 메모리(RAM)나 캐시 메모리(Cache)에 비해 읽기/쓰기 속도가 훨씬 빠릅니다.
  - 용량은 매우 적지만, CPU의 ALU(산술논리장치)와 제어장치가 데이터에 즉각 접근할 수 있도록 도와줍니다.
  - 연산 중 발생하는 중간 결과값, 메모리 주소, 명령어, CPU의 현재 상태 정보(플래그) 등을 임시 보관합니다.

---

## 2. 시스템 버스 (System Bus)
- **개념**: CPU, 메인 메모리, I/O 장치 간에 데이터와 제어 신호를 주고받는 통로입니다.

```text
       ┌───────────┐
       │    CPU    │
       └─────┬─────┘
  ───────┼─────┼─────┼─────── Control Bus (제어 신호: Read, Write 등)
  ───────┼─────┼─────┼─────── Address Bus (주소 전달: Uni-directional)
  ───────┼─────┼─────┼─────── Data Bus    (데이터 전달: Bi-directional)
       ┌─┴─────┴─────┴─┐
       │   메인 메모리   │
       └───────────────┘
```

- **제어 버스 (Control Bus)**:
  - CPU가 각 장치에 읽기(RD), 쓰기(WR) 명령 신호, 인터럽트 신호, 타이밍 신호 등을 전달하는 통로입니다.
- **주소 버스 (Address Bus)**:
  - CPU가 읽거나 쓰려는 메모리 위치나 I/O 포트의 주소(Address) 정보를 전달하는 단방향(Uni-directional) 통로입니다.
  - 주소 버스의 폭(비트 수)에 따라 CPU가 접근 가능한 최대 메모리 용량이 결정됩니다 (예: 32비트 주소 버스 $\rightarrow 2^{32} = 4\text{GB}$).
- **데이터 버스 (Data Bus)**:
  - CPU와 메모리, I/O 장치 사이에서 실제 데이터 및 명령어를 주고받는 양방향(Bi-directional) 통로입니다.

## 3. C언어 / 프로세스 메모리 구조 (Memory Structure)
- **개념**: C 언어 프로그램이 실행되어 메모리(RAM)에 로드될 때 구성되는 5개 영역입니다.

```text
  [ 높은 메모리 주소 (0xFFFFFFFF) ]
  ┌───────────────────────────────┐
  │   Stack Segment (스택)        │  ▼ (낮은 주소 방향으로 확장)
  ├───────────────────────────────┤
  │               │               │
  │               ▼               │
  │               ▲               │
  │               │               │
  ├───────────────────────────────┤
  │   Heap Segment (힙)           │  ▲ (높은 주소 방향으로 확장)
  ├───────────────────────────────┤
  │   BSS Segment                 │  (초기화되지 않은 전역/정적 변수)
  ├───────────────────────────────┤
  │   Data Segment                │  (초기화된 전역/정적 변수)
  ├───────────────────────────────┤
  │   Code / Text Segment (코드)  │  (기계어 명령어 코드 / Read-Only)
  └───────────────────────────────┘
  [ 낮은 메모리 주소 (0x00000000) ]
```

- **코드 영역 (Code / Text Segment)**:
  - 실행할 C언어 소스코드의 **기계어 명령어(Assembly/Machine Code)**가 저장되는 영역입니다.
  - 프로그램 실행 중 코드 변경을 막기 위해 **읽기 전용(Read-Only)**으로 보호됩니다.
- **데이터 영역 (Data Segment)**:
  - 초기화된 전역변수(Global) 및 **정적변수(Static)**가 저장되는 영역입니다.
  - 프로그램 시작 시 할당되고 종료 시 해제됩니다.
- **BSS 영역 (BSS Segment - Block Started by Symbol)**:
  - 초기화되지 않은 전역변수 및 정적변수가 저장되는 영역입니다.
  - 프로그램 실행 시 OS에 의해 모두 `0`으로 자동 초기화됩니다.
- **힙 영역 (Heap Segment)**:
  - 프로그래머가 동적으로 메모리를 할당하는 영역 (`malloc()`, `calloc()`, `free()` 등).
  - 낮은 주소에서 높은 주소 방향으로 할당됩니다.
- **스택 영역 (Stack Segment)**:
  - 지역변수(Local), 매개변수(Parameter), 함수 호출 후 돌아갈 리턴 주소(Return Address) 등이 저장되는 영역입니다.
  - 함수가 호출될 때 생성되고 종료되면 자동으로 반환되며, 높은 주소에서 낮은 주소 방향으로 할당됩니다.

## 4. x86 프로세서 핵심 정리 (전체 통합요약)

| 분류 | 핵심 내용 |
| :--- | :--- |
| **CPU 제어/연산** | ALU (산술/논리연산), CU (명령어 해독 및 제어), Register (CPU 내 초고속 임시 저장소) |
| **시스템 버스** | Address Bus (주소 전달), Data Bus (데이터/명령어 전달), Control Bus (제어 신호 전달) |
| **동작 모드** | Real Mode (1MB, MS-DOS), Protected Mode (4GB, 보호기능), Virtual-8086 (하위호환) |
| **범용 레지스터** | EAX (누산기/반환값), EBX (베이스), ECX (카운터), EDX (데이터 보조), EBP/ESP (스택 프레임) |
| **특수 레지스터** | EIP (다음 실행 명령어 주소), EFLAGS (CF, OF, ZF, SF 등 상태 플래그) |
| **메모리 구조** | Code (명령어), Data/BSS (전역/정적 변수), Heap (동적 할당), Stack (지역변수/함수호출) |
